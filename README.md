### Jinchen Zhao

PhD candidate in Applied Physics at Yale University, advised by Logan Wright.

[Homepage](https://jinchen-zhao.github.io) · [Google Scholar](https://scholar.google.com/citations?hl=en&user=Ib53fIQAAAAJ) · [X](https://x.com/JinchenZhaoo) · [LinkedIn](https://www.linkedin.com/in/jinchenzhao/)

I work on unconventional computing (optical, quantum and thermodynamic) in theory and experiment. I study how analog noise limits computation at ultra-low energy, and I build tools that use large language models to automate scientific research.

**Projects**

- [schematic-figure](https://github.com/lgwrightlab/schematic-figure): a Claude skill that draws publication-quality scientific schematics ([blog post](https://jinchen-zhao.github.io/blog/schematic-figure/))
- [cascaded-nonlinearity](https://github.com/jinchen-zhao/cascaded-nonlinearity): a tutorial and solver for a tunable, even negative, χ<sup>(3)</sup> from cascaded χ<sup>(2)</sup>
